# Paradise Nursery

Paradise Nursery is an online plant shop built with React and Redux Toolkit.
Customers can browse houseplants grouped into categories, add them to a
shopping cart, adjust quantities, and see the total cost of their order.

## Features
- Landing page with the company name, a short description, and a "Get Started" button
- Product listing page with 18 houseplants in 3 categories (thumbnail, name, price)
- "Add to Cart" button that disables after the plant is added
- Navbar with Home, Plants, and Cart links, plus a live cart item count
- Shopping cart with quantity controls, delete button, subtotal per plant, and total amount
- Checkout button ("Coming Soon") and Continue Shopping button

## Tech Stack
React, Redux Toolkit, Vite

## Run Locally
    npm install
    npm run dev
